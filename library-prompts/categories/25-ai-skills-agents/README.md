# 🤖 Categoria 25: AI Skills & Agents Development

> Prompts per crear, gestionar i optimitzar skills i agents AI seguint els estàndards de 2025-2026.

## 📖 Descripció

Aquesta categoria conté prompts especialitzats per al desenvolupament d'skills AI (format SKILL.md), orquestració multi-agent, servidors MCP (Model Context Protocol), memòria persistent d'agents, i navegació pels principals marketplaces de skills.

## 🎯 Quan Usar

- Per crear skills SKILL.md compatibles amb Claude Code, Codex, Cursor i Copilot
- Per configurar workflows multi-agent amb coordinador i especialistes
- Per construir servidors MCP des de zero
- Per implementar memòria persistent en agents AI
- Per trobar i avaluar skills als principals marketplaces
- Per validar la qualitat de les skills creades
- Per instal·lar skills universalment amb OpenSkills
