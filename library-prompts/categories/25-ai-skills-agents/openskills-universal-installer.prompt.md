# OpenSkills Universal Installer — Cross-Platform Skill Installation

## Prompt

You are an expert AI Development Environment Engineer. Your task is to help me install and configure **OpenSkills**, the universal skill installer that works across all major AI coding agents. You will guide me through installation, configuration, skill management, and cross-platform synchronization.

### Context & Background

**OpenSkills** is the universal package manager for AI skills. Just as `npm` manages JavaScript packages, OpenSkills manages AI skills across all major coding agents. One command installs a skill on any supported platform.

**Problem it solves**: Each AI agent stores skills differently:
- Claude Code: `~/.claude/skills/` or project `AGENTS.md`
- Cursor: `.cursor/skills/` or `.cursorrules`
- Copilot: `.github/copilot-instructions.md`
- Codex: `AGENTS.md` or `agents/`
- Windsurf: `.windsurfrules`
- Cline: `.clinerules`

OpenSkills abstracts this away — you install once, it deploys everywhere.

### Your Instructions

**STEP 1 — Install OpenSkills**

```bash
# Install globally via npm
npm install -g openskills

# Verify installation
openskills --version

# Alternative: use npx without installing
npx openskills --help
```

**Requirements:**
- Node.js 18+ (LTS recommended)
- npm 9+
- Works on: Windows, macOS, Linux

**STEP 2 — Initial Setup**

```bash
# Initialize OpenSkills in your project
cd your-project
openskills init

# This creates:
# .openskills/
# ├── config.json    # Configuration
# ├── installed/     # Downloaded skill files
# └── sync-map.json  # Maps skills to agent locations

# Configure which agents to target
openskills config set agents "claude-code,cursor,copilot"

# Or target all detected agents
openskills config set agents "auto"
```

**Configuration file** (`.openskills/config.json`):
```json
{
  "version": "1.0",
  "agents": ["claude-code", "cursor", "copilot", "codex", "windsurf", "cline"],
  "auto_sync": true,
  "skill_sources": [
    "https://skillsmp.com",
    "https://skills.directory",
    "https://skills.sh"
  ],
  "install_path": ".openskills/installed",
  "preferences": {
    "max_token_size": 8000,
    "prefer_verified": true,
    "auto_update": false
  }
}
```

**STEP 3 — Install Skills**

```bash
# Search for skills
openskills search "django rest api"
openskills search "react typescript" --source skillsmp
openskills search "docker deployment" --verified-only

# Install a skill
openskills install django-rest-builder
openskills install react-component-generator
openskills install docker-deploy --version 2.0

# Install from a specific source
openskills install skillsmp:django-rest-builder
openskills install github:user/repo/skill-name

# Install from a URL
openskills install https://raw.githubusercontent.com/user/repo/main/SKILL.md

# Install from a local file
openskills install ./my-custom-skill.md

# Install multiple skills at once
openskills install django-rest-builder react-component-generator docker-deploy
```

**STEP 4 — Sync to All Agents**

```bash
# Sync all installed skills to all configured agents
openskills sync

# Sync to a specific agent only
openskills sync --agent cursor
openskills sync --agent claude-code

# See what will be synced (dry run)
openskills sync --dry-run

# Force re-sync (overwrites existing files)
openskills sync --force
```

**What `openskills sync` does for each agent:**

| Agent | Action | File Location |
|-------|--------|---------------|
| **Claude Code** | Creates/updates SKILL.md files | `~/.claude/skills/<name>.md` or project `AGENTS.md` |
| **Cursor** | Creates/updates skill files | `.cursor/skills/<name>.md` |
| **GitHub Copilot** | Appends to instructions file | `.github/copilot-instructions.md` |
| **Codex CLI** | Creates/updates AGENTS.md | Project root `AGENTS.md` or `agents/<name>.md` |
| **Windsurf** | Appends to rules file | `.windsurfrules` |
| **Cline** | Appends to rules file | `.clinerules` |
| **OpenCode** | Creates skill files | `.opencode/skills/<name>.md` |

**STEP 5 — AGENTS.md Compatibility Layer**

OpenSkills automatically generates an `AGENTS.md` file that works as a universal compatibility layer:

```markdown
# AGENTS.md — Auto-generated by OpenSkills
# This file provides instructions to AI coding agents.
# Compatible with: Codex CLI, Claude Code, and any agent that reads AGENTS.md

## Installed Skills

### django-rest-builder v2.1.0
<!-- Source: skillsmp:django-rest-builder -->
When the user asks to create a REST API endpoint:
1. Use Django REST Framework
2. Create serializer in serializers.py
3. Create viewset in views.py  
4. Register URL in urls.py
5. Add test in tests/test_api.py

### react-component-generator v1.5.0
<!-- Source: skillsmp:react-component-generator -->
When the user asks to create a React component:
1. Create functional component with TypeScript
2. Use props interface (not type)
3. Include default export
4. Add Storybook story file
5. Add unit test with React Testing Library

---
*Generated by OpenSkills. Do not edit manually — changes will be overwritten on next sync.*
*Run `openskills sync` to regenerate.*
```

**STEP 6 — Manage Installed Skills**

```bash
# List installed skills
openskills list
openskills list --verbose

# Show skill details
openskills info django-rest-builder

# Update a skill
openskills update django-rest-builder
openskills update --all

# Remove a skill
openskills remove django-rest-builder

# Remove and clean up from all agents
openskills remove django-rest-builder --purge

# Export your skill configuration (portable)
openskills export > my-skills.json

# Import skills on another machine
openskills import my-skills.json
```

**STEP 7 — Cross-Platform Setup Guide**

#### Windows
```powershell
# Install Node.js (if not installed)
winget install OpenJS.NodeJS.LTS

# Install OpenSkills
npm install -g openskills

# Configure
cd C:\Users\YourUser\YourProject
openskills init
openskills config set agents "auto"

# Install and sync
openskills install django-rest-builder
openskills sync
```

#### macOS
```bash
# Install Node.js (if not installed)
brew install node

# Install OpenSkills
npm install -g openskills

# Configure
cd ~/projects/your-project
openskills init
openskills config set agents "auto"

# Install and sync
openskills install django-rest-builder
openskills sync
```

#### Linux
```bash
# Install Node.js (if not installed)
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# Install OpenSkills  
npm install -g openskills

# Configure
cd ~/projects/your-project
openskills init
openskills config set agents "auto"

# Install and sync
openskills install django-rest-builder
openskills sync
```

**STEP 8 — Advanced Usage**

```bash
# Create a skill from your project's conventions
openskills create --from-project
# Analyzes your codebase and generates a skill file

# Publish your skill to SkillsMP
openskills publish ./my-custom-skill.md
# Requires SkillsMP account

# Run skill health check
openskills doctor
# Checks: Node version, agent detection, sync status, broken links

# Watch mode (auto-sync on skill file changes)
openskills watch

# CI/CD integration
# In your CI pipeline:
openskills install --from-lockfile  # Install exact versions
openskills sync --agent codex       # Sync for CI agent
```

**STEP 9 — Troubleshooting**

| Issue | Cause | Solution |
|-------|-------|----------|
| `openskills: command not found` | Not in PATH | `npm install -g openskills` or use `npx openskills` |
| Skills not picked up by agent | Agent needs restart | Close and reopen the AI agent / editor |
| Sync creates empty files | Skill format incompatible | `openskills validate <skill>` to check format |
| `AGENTS.md` conflicts with existing | Manual AGENTS.md exists | Add `<!-- openskills:managed -->` marker or use `--merge` flag |
| Permission denied on sync | File permissions | Run with appropriate permissions or check file ownership |
| Skill not found | Wrong source | Try: `openskills search <name> --all-sources` |
