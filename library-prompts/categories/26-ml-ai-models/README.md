# 🧠 Categoria 26: ML/AI & Models (2026)

> Prompts per integrar, avaluar, comparar i optimitzar models d'intel·ligència artificial i machine learning — actualitzat a febrer de 2026.

## 📖 Descripció

Aquesta categoria conté prompts especialitzats per treballar amb els principals models d'IA del 2026: GPT-5.2, Claude Opus 4.6, Gemini 2.0 Flash, DeepSeek V4, i Voxtral Transcribe 2. Cobreix migració d'APIs, optimització de prompts, pipelines de ML complets, benchmarking, fine-tuning amb LoRA/QLoRA, integració multimodal i transcripció de veu.

## 🎯 Quan Usar

- Per migrar de GPT-4o a GPT-5.2 abans del deadline del 13 de febrer de 2026
- Per optimitzar prompts específicament per Claude Opus 4.6
- Per construir pipelines completes de ML amb HuggingFace
- Per avaluar i comparar models amb benchmarks estandarditzats
- Per fer fine-tuning eficient amb LoRA/QLoRA en GPUs de consum
- Per integrar Google Gemini 2.0 Flash i desenvolupar plugins
- Per implementar transcripció de veu amb Voxtral (local o cloud)
- Per escollir el model correcte per al teu cas d'ús específic
